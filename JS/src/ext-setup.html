Browsers

Only browsers installed on this computer are listed. Connected means the extension is in the browser.

Scroll to see a guide on how to install the extension.
  1. Brave, Edge, and other Chromium browsers
    1. Press Install.
    2. Turn on Developer mode in Extensions.
  2. Google Chrome
    1. Press Copy path.
    2. Press Install. Chrome will open, then go to the extension manager.
    3. Turn on Developer mode.
    4. Press Load unpacked.
    5. Paste the path in the Folder box at the bottom, then press Select Folder.
  3. Firefox and Firefox-based browsers
    1. Press Copy.
    2. Press Install. The browser opens about:debugging.
    3. Press Load Temporary Add-on.
    4. Paste the path in the box at the bottom, then press Open.
